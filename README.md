# Diapositiva: La lectura y los tipos de lectura

Sitio estático listo para publicar en GitHub Pages.

Archivo principal:

- `index.html`

Contenido:

- Diapositiva animada estilo Canva.
- Paneles con tipos de lectura.
- Imagen educativa generada para la presentación.
- Diseño responsive para pantalla ancha y móvil.

Para publicarlo en GitHub Pages:

1. Crea un repositorio público en GitHub.
2. Sube `index.html`, `.nojekyll`, `README.md` y la carpeta `assets`.
3. En el repositorio, ve a **Settings > Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/root`.
